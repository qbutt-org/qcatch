qcatch

A browser extension for downloading videos

qcatch finds video, audio and subtitles on the page you have open and saves selected tracks.

Download for Windows All files

Browser installation

The EXE installer prepares qcatch and the extension folder. Open the extensions page in Edge or Chrome, enable Developer mode, click Load unpacked and select the extension folder shown in the setup instructions. The extension is not in the store yet.

Open a video page and start playback. qcatch will show the streams, audio tracks and subtitles it finds. Choose what to save.

Downloads and playback

Save video with audio and subtitles, or save a separate audio stream.

Open in qplay sends the selected video to installed qplay. Separate actions send it to qbutt for watching or downloading. The regular download button uses qcatch.
